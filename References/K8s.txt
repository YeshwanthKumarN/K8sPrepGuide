Beginner (Concepts & Basics)
----------------------------

1. What is Kubernetes?

Kubernetes (K8s) is an open-source container orchestration platform for automating deployment, scaling, and management of containerized applications.

🟩 Example: In GKE, Google handles control plane provisioning for you, and you manage node pools and workloads.


2. What is a Pod in Kubernetes?

A Pod is the smallest deployable unit, which can contain one or more containers that share storage, network, and lifecycle.

✅ In GKE: Each pod runs on a node in a GKE node pool, and is monitored via Cloud Monitoring.


3. What is a Node?

A Node is a virtual or physical machine on which Kubernetes runs pods.

In GKE, nodes are managed in Node Pools, which can be autoscaled.


4. What is a Cluster?

A Kubernetes cluster is a set of nodes that run containerized applications managed by Kubernetes.

GKE automates cluster creation with regional or zonal high-availability.


5. What is kubelet?

Kubelet is an agent that runs on each node and ensures that the containers are running as expected.


6. What is a ReplicaSet?

A ReplicaSet ensures a specified number of pod replicas are running at any time. Useful for scaling horizontally.

    replicas: 3


7. What is a Deployment in Kubernetes?

A Deployment provides declarative updates for Pods and ReplicaSets. It supports rolling updates and rollbacks.

In GKE, use kubectl apply or GKE Autopilot console to deploy apps.


8. What is a Service?

A Service exposes your pods to other pods or the internet, depending on type (ClusterIP, NodePort, LoadBalancer).

LoadBalancer in GKE creates a Google Cloud Load Balancer automatically.


9. Difference between StatefulSet and Deployment?

Deployment: Stateless apps, scaled easily, recreated freely.

StatefulSet: Persistent identity, storage, and ordering for pods (e.g., databases).


10. What is a ConfigMap and Secret?

ConfigMap: Stores non-confidential configuration data.

Secret: Stores sensitive data like passwords, tokens.

GKE integrates with Secret Manager for better secret management.


Intermediate (Networking, Storage, Scheduling)
----------------------------------------------

11. Explain Kubernetes Networking Basics.

Flat network model: every pod can communicate with any other pod.

Uses CNI plugins for network policies and configuration.

GKE uses VPC-native clusters (alias IPs) for better control and security.


12. What is a ServiceAccount?

Used by pods to interact with the Kubernetes API. In GKE, bind to GCP IAM roles for workload identity.


13. Explain Readiness and Liveness Probes.

Liveness: Checks if the app is running.

Readiness: Checks if the app is ready to receive traffic.

        livenessProbe:
            httpGet:
                path: /healthz
                port: 8080


14. How does Horizontal Pod Autoscaler work?

Scales pods based on CPU/memory/custom metrics.

GKE integrates HPA with Cloud Monitoring metrics and supports custom metrics APIs.


15. What is a DaemonSet?

Ensures a pod runs on all (or some) nodes.

Useful for log agents or monitoring agents in GKE like Cloud Ops Agent.


16. What is a Job and CronJob?

Job: Runs once to completion.

CronJob: Runs on a schedule.


17. What is a Namespace?

Logical partitions for separating workloads and access control.

GKE supports namespace-level IAM bindings.


18. How is persistent storage handled in K8s?

Via PersistentVolumes (PV) and PersistentVolumeClaims (PVC).

GKE uses GCE Persistent Disks or Filestore as backend.


19. What is a NetworkPolicy?

Defines how pods communicate with each other.

In GKE, VPC-native networking and Calico plugin are used for enforcing policies.


20. What is Pod Affinity and Anti-affinity?

Rules to place pods together or apart.

        affinity:
            podAntiAffinity:
                requiredDuringSchedulingIgnoredDuringExecution:


Advanced (Design, Security, Resilience)
-----------------------------------------

21. Explain the Control Plane Components.

kube-apiserver: Entry point for API requests.

etcd: Key-value store.

kube-scheduler: Assigns pods to nodes.

kube-controller-manager: Manages controllers.

cloud-controller-manager: Integrates with cloud providers.

GKE hosts this in a managed control plane, secured and auto-patched.


22. How does Kubernetes handle failures?
    
    Self-healing via controllers.

    Health checks.

    Rescheduling.

    Pod eviction from failed nodes.


23. Explain RollingUpdate and Rollback in Deployments.

    strategy:
        type: RollingUpdate

    kubectl rollout undo deployment <name>


24. What is Taints and Tolerations?

Taints prevent pods from scheduling unless tolerations match.

In GKE, use node taints for GPU or node pool separation.


25. What are Init Containers?

Run before main containers. Used for setup logic.


26. What is the difference between Requests and Limits?

        resources:
        requests:                   Guaranteed while provisioning
            cpu: "100m"
            memory: "128Mi"
        limits:                     
            cpu: "200m"
            memory: "256Mi"


27. How does Kubernetes perform pod scheduling?

Scheduler selects a node based on:

    NodeAffinity

    Resource Requests

    Taints/Tolerations

    Inter-pod affinity rules


28. What are Admission Controllers?

They intercept requests to the API server before persistence.

In GKE, use OPA Gatekeeper or PodSecurityPolicies (deprecated in 1.25+).


29. What is a Sidecar Pattern?

An extra container in a pod that enhances functionality — e.g., for logging, service mesh, proxies.


30. How is Ingress different from Service?

Service: Internal or external load balancing.

Ingress: Layer 7 routing with rules.

GKE supports GKE Ingress, Gateway API, and Istio-based Ingress.


Scenario-Based / Troubleshooting / Real-World
---------------------------------------------


31. How do you debug a pod in CrashLoopBackOff?

        kubectl describe pod <name>
        kubectl logs <name>
    
    Add readiness probe or handle signal gracefully.


32. A deployment is stuck in progress. What do you check?

    Check rollout status: kubectl rollout status

    Events: kubectl describe

    HPA conflicts, image pull errors


33. How to ensure zero downtime deployments?
 
        Use readiness probes.

        RollingUpdate strategy.

        PreStop hooks.


34. What happens when a node dies?

    Kubelet stops sending heartbeats.

    Controller marks node as NotReady.

    Pods are evicted and rescheduled.

    GKE handles node repair or replacement automatically.


35. How to implement blue-green or canary deployments in K8s?

    Manual:
        Create separate deployments/services.

        Use labels/selectors and route gradually.

    Automatic:

    Use GKE traffic splitting via Ingress or Anthos Service Mesh.


36. How do you secure Kubernetes workloads?

    Use Secrets.

    Limit RBAC.

    Use PSPs / OPA Gatekeeper.

    NetworkPolicies.

    Run as non-root.


37. What is Workload Identity in GKE?

It allows GKE workloads to access GCP APIs using IAM, without storing keys.


38. What is Pod Disruption Budget (PDB)?

Ensures a minimum number of pods are always available during voluntary disruptions.

    minAvailable: 2


39. Difference between Soft and Hard Pod Eviction?

Soft: Graceful draining (via PDB).

Hard: Immediate eviction (e.g., node failure).


40. How do you clean up resources in Kubernetes?

    kubectl delete -f <manifest>

Or use label selectors:

    kubectl delete pod -l app=myapp


41. How does service discovery work in K8s?

    Via DNS: <service>.<namespace>.svc.cluster.local

    Internal ClusterIP


42. What is the use of kubectl exec, logs, and port-forward?

exec: Run command inside pod

logs: View pod logs

port-forward: Access local port to pod's port


43. How do you handle secrets securely in GKE?

Use Kubernetes Secrets (encrypted at rest).

Integrate with Google Secret Manager.

44. How to access a pod running on private GKE cluster?

    External Network: Use Cloud NAT or IAP TCP forwarding.

    Same Network: Use bastion host or VPN.


45. How to isolate workloads in GKE?

    Use Namespaces

    Use Node Pools

    Use NetworkPolicies

    Apply RBAC


Architectural Design & CI/CD
----------------------------


46. How do you implement GitOps in GKE?

    1. Use Config Sync, ArgoCD or FluxCD. Store manifests in Git.

    2. Use Cloud Build triggers for PRs.


47. How do you implement CI/CD with GKE?

        Cloud Build + Artifact Registry + GKE

        Use Skaffold for local development


48. What is Autopilot vs Standard GKE?

    Autopilot: Fully managed nodes, per-pod billing.

    Standard: Full node control.



49. How to configure node auto-scaling in GKE?

    Enable Cluster Autoscaler in node pool.

    Configure min/max node count.


50. What is Resource Quota and LimitRange?

Quota: Limits on resource usage per namespace.

LimitRange: Default requests/limits for containers.
